# OneWorks integration

OneWorks Avatar SDK and editor: 1.0.0-rc.9. Public versioned definitions are in avatar-presets.json. SDK, React, React DOM and Scheduler license copies are in vendor/.

avatar-atlas-v2 contains public SDK captures: 2048×2048 transparent PNG sheets, 64 frames of 256×256 per sheet, three application-authored motion clips per character. These are not the complete official animation library. The camera/export background is transparent; editor UI backgrounds are not avatar pixels.

alpine-light-background-v1.png was generated with the native image generation tool; its prompt is stored alongside it. It is a landscape wallpaper, not an HDR panorama.
