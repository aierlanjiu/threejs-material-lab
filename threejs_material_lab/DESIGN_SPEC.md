# Three.js 材质实验室升级设计说明书 (Design Spec)

## 1. 概述与目标

本项目为 Three.js 单页 3D 材质文字立方体实验室的全面升级，主要解决并达成以下三大核心目标：
1. **高级材质与影棚级光影质感**：基于 Three.js r166 PBR 物理光影系统，引入真实物理色散（Dispersion）、体积衰减（Attenuation）、影棚反射环境（Studio Softbox HDR）、后处理辉光（Bloom）以及高阶 3D 激光内雕/烫金文字工艺。
2. **4×4 / 5×5 智能矩阵与 3D 多层立体排版（A+C 方案）**：支持自动识别字数并匹配最佳方阵（3×3、4×4、5×5）及立体多层雕塑排版，未填满网格自动以纯净原材质方块补齐，保持整体艺术方阵完整性；支持单行/长文本自动流式分词排版。
3. **修复云朵与全材质色泽联动 Bug**：修复云朵材质写死白色 `#ffffff` 的问题，完善次表面散射与透光质感，实现调色盘、预设色卡对所有材质（包括高透水晶、极光棱镜、北极冰晶、透光磨砂、黑曜烟晶、重磅真丝、羊绒针织、蓬松彩云）的即时精确渲染。

## 2. 详细架构与模块设计

### 2.1 规格矩阵与排版引擎 (`MatrixLayoutEngine`)
- **规格模式支持**：
  - `auto` (自动推荐：1~9字 3×3, 10~16字 4×4, 17~25字 5×5, 26+字 自动开启立体双层或 6×6)
  - `3x3` (固定 9 格方阵)
  - `4x4` (固定 16 格方阵)
  - `5x5` (固定 25 格方阵)
  - `3d_stack` (立体双层 4×4×2 雕塑堆叠)
- **文本流式处理**：
  - 自动过滤多余空白符，按字符数组顺序排列到网格位置 $(x, y, z)$。
  - 支持直接输入连续长句（如“WE NEED MORE CRYSTAL 晶莹剔透”），无需手动分行。
- **晶体底座补齐 (A 方案)**：
  - 当字符数小于网格总数 $N \times M$ 时，剩余网格生成不带文字贴图的纯净原材质方块，保证整体方阵雕塑的完整几何轮廓。
- **立体多层排版 (C 方案)**：
  - 在立体模式或文字超出单层容量时，按前后层（Z 轴偏移 $1.2$ 单位）或上下层堆叠，中心自动居中对齐，相机焦点自动适配。

### 2.2 物理材质系统升级 (`MaterialFactory`)

| 材质名称 | 核心物理参数与视觉特性 | 色彩与交互响应 |
| :--- | :--- | :--- |
| **高透天然水晶 (Crystal)** | `transmission: 1.0`, `ior: 1.54`, `thickness: 1.4`, `roughness: 0.015`, `dispersion: 0.12`, `clearcoat: 1.0`, `attenuationDistance: 5.0` | 边缘形成光学彩虹色散与明亮高光带，内部具有通透体积衰减色 |
| **极光棱镜 (Prism)** | `transmission: 1.0`, `ior: 1.78`, `thickness: 1.6`, `roughness: 0.005`, `dispersion: 0.28`, `iridescence: 0.85` | 强折射率与高色散，转动视角时折射出炫目彩虹光斑 |
| **北极冰晶 (Ice)** | `transmission: 0.96`, `ior: 1.31`, `roughness: 0.06`, `bumpMap: noiseTexture (scale 0.04)`, `thickness: 1.3` | 微粗糙冰霜质感与冷光漫反射，呈现天然冻结冰晶层次 |
| **透光磨砂 (Frosted)** | `transmission: 0.82`, `ior: 1.46`, `roughness: 0.36`, `thickness: 0.9`, `clearcoat: 0.3` | 细腻的天鹅绒般透光毛玻璃，柔和漫透射 |
| **黑曜/琥珀烟晶 (Smoke/Amber)**| `transmission: 0.65`, `ior: 1.55`, `thickness: 1.5`, `roughness: 0.05`, `attenuationDistance: 1.2` | 内部高浓度色浆吸收，呈现黑曜石、烟晶、蜜蜡琥珀的深邃光泽 |
| **重磅真丝 (Silk)** | `roughness: 0.30`, `sheen: 1.0`, `sheenColor: color+white_blend`, `normalMap: weaveTexture`, `clearcoat: 0.05` | 伴随视角的各向异性光泽，微细织纹法线 |
| **羊绒针织 (Wool)** | `roughness: 0.95`, `sheen: 0.9`, `bumpMap: noiseTexture`, `fuzzShell` 细微绒毛轮廓 | 温暖哑光与边缘微绒毛轮廓 |
| **蓬松体积彩云 (Cloud)** | 复合多球软体拟合 + `MeshPhysicalMaterial` (`roughness: 0.9`, `sheen: 0.6`, `opacity: 0.88`, `depthWrite: false`) + 完整响应 `ui.color` | 彻底修复色彩被忽略问题，呈现带有次表面柔光的轻盈梦幻彩云 |

### 2.3 文字雕刻工艺系统 (`TypographyFactory`)
- **3D 激光内雕 (Laser Engraving)**：
  - 文字悬浮于水晶正中心，带微发光与半透明磨砂折射，视角旋转时与外表面产生真实空间视差。
- **烫金与金属徽标 (Metallic Foil)**：
  - 高反光金属质感与浮雕法线，适合奢华品牌印记。
- **智能高对比度模式 (Smart Contrast)**：
  - 自动根据选定色彩的明度（Luminance）与材质透光度，自适应切换纯白、深黑灰或烫金字色，确保文字清晰可辨。

---

### 2.4 光影与渲染管线升级 (`RenderPipeline`)
- **多点影棚布光系统**：
  - 主光（DirectionalLight with PCFSoftShadowMap, 4K resolution, 柔和接触阴影）
  - 冷色高亮轮廓光（Cool Rim Light）
  - 暖色柔和补光（Warm Fill Light）
  - 顶部聚光闪烁光（Top Sparkle Light）
  - 底部地光反弹（Ground Bounce Light）
- **高动态 Studio 环境贴图**：
  - 通过 `PMREMGenerator` 生成带高动态柔光箱（Softbox）阵列的演播室环境反射。
- **后处理特效 (Post-processing)**：
  - `EffectComposer` + `RenderPass` + `UnrealBloomPass`（轻微阈值 0.85，半径 0.4，强度 0.35），为玻璃倒角折射与激光文字带来珠宝级璀璨光晕。
- **Studio 镜面微磨砂底座**：
  - 接收高品质渐变阴影与微弱倒影，衬托方块悬浮与落地体量感。

## 3. UI 交互控制项规划

1. **文本输入区**：大文本框，支持直接粘贴连续段落或多行字符。
2. **规格排版选择器**：
   - 按钮组 / 下拉框：`自动 (Auto)` | `3×3 (9字)` | `4×4 (16字)` | `5×5 (25字)` | `立体双层 (4×4×2)`
   - 补齐开关：`晶体补齐 (填充空格)` 开/关
3. **文字工艺选择器**：
   - `3D 激光内雕` | `极简印刷` | `奢华烫金`
4. **材质与色泽选择器**：
   - 8 种精选材质切换
   - 8 色经典预设色卡（冰晶蓝、极光紫、晨曦粉、翡翠绿、薄荷青、琥珀金、深海蓝、黑曜灰）+ 调色盘
   - 物理微调滑块（粗糙度、透射比、厚度、IOR 折射率、色散强度、环境反射、灯光强度、辉光强度）
5. **视角与展示控制**：
   - 透视 FOV、重置视角、自动旋转开关、预设视角（正面/俯视/特写）。

## 4. 验证与验收标准

1. **材质真实感验收**：
   - 水晶倒角在转动时有流动的高光带与彩虹色散，非平面塑料贴片。
   - 地面阴影柔和自然，暗部通透。
2. **排版规格验收**：
   - 输入 4 个字在 4×4 模式下生成 4 个文字块 + 12 个纯净水晶块，构成完整 4×4 方阵。
   - 切换 5×5 模式即刻重新排布为 5×5 方阵。
   - 切换立体多层模式即刻呈现前后立体堆叠。
3. **色彩与云朵修复验收**：
   - 选择红色/粉色/蓝色，云朵材质立即呈现对应色彩的透光彩云，无残留纯白写死问题。
   - 切换预设色卡即时生效。
