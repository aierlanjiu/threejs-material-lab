# 「幻 / HUAN」拟态荔枝 3D 桌面萌宠 CMF 材质与表情设计稿

> **设计基准**：基于对话 `codex://threads/01a09d42-c6a9-7702-860b-0df390fb2cc6` 的核心艺术指导要求：
> 1. **形态统一**：拟态荔枝桌面萌宠，放弃其他几何/立方体形象，保留丰满水润的圆锥卵形轮廓与稳定的平坦底座。
> 2. **果肉主体**：主体约 90% 为晶莹饱满的剥壳荔枝果肉（Peeled Lychee Aril），光滑温润，带浅浅的自然纵向果瓣纹理与水润微透感；拒绝全壳包覆。
> 3. **点缀元素**：仅在背侧/下边缘保留 <10% 真实荔枝带鳞斑的破损果壳点缀，顶部配极细小天然短木枝与一片小巧深绿荔枝叶。
> 4. **五官与表情系统**：
>    - **Hero 主视觉**（左上 3/4 视角）：温柔浅笑、专注亲和
>    - **JOY**：欢喜眯眼（月牙笑眼、嘴角上扬、身体轻微弹润起伏）
>    - **CURIOUS**：好奇探索（头部微歪、眼神斜上视、小嘴微闭）
>    - **SPEAK**：互动交流（眼神清亮、嘴巴微张呈小 'o' 形）
>    - **SLEEP**：安静休憩（双目微阖、身形舒展下沉、静谧陪伴）
> 5. **宏观材质微距圈**（右上）：展示核心材质微观质感、次表面散射与边缘光泽。
