## 🌟 项目双旗舰架构

本项目为纯前端轻量 WebGL / Three.js 架构，包含两大旗舰体验与一套衍生棋局：

1. 🌰 **『 荔 』(LI) · 暖光藏品伴侣室 (`mascot_studio.html`)**：
   - 具身 3D 萌系潮玩伴侣（荔小卫 / 荔小星）
   - 24 款工坊大师 CMF 奢华配色矩阵（果壳白玉、故宫剔红、航天钛银等）
   - 雪沐怪诞手绘透明 UI 资产体系、Disney 12 原则体积守恒弹性形变与 118 BPM 音乐共振起舞
   - 智能对话手记与语音控制表情
2. 💎 **『 律 』(LÜ) · 3D 物理材质与声波共振工作台 (`index.html`)**：
   - 统摄音频实时 FFT 频谱分析与声波频率律动（6 大声波物理矩阵形态）
   - 12 款纯净 PBR 物理材质（色散、IOR、体积衰减吸收、各向异性真丝）
   - 3D 激光内雕、活体表情注视跟随、编排运镜导演与 60FPS 母带录制直出 MP4
3. ♟️ **『 弈律 』· 3D 中国象棋 (`xiangqi.html`)**：
   - 复用 LÜ 物理材质与影棚柔光的东方藏品级 3D 象棋对弈引擎

## ✨ 核心特性与 Workbench 2.0 架构

本项目全新升级为 **Workbench 2.0 浅色影棚玻璃拟态工作台 (Studio Bauhaus Light Edition)**，全量搭载矢量 SVG 图标系统：

### 1. 🎛 顶部 Master Deck HUD
- **发光品牌主标**：极简单字「律」字标 + 动态 60 FPS 帧率指示 + 实时乐章流变进度徽标。
- **母带播放中枢**：实时音频频谱条（Audio Spectrum）、播放/暂停/上一首/下一首/停止控制、内置歌单切换与本地批量音频上传（MP3/WAV）。
- **快捷工具集**：全变量流变大开关、歌名序幕开关、歌词展示开关、60FPS 母带录制触发按钮、预设视角切换（正面/等轴/俯视）。

### 2. 🌊 底部 Dynamic Flow Dock
- **6 大声波物理矩阵形态**：
  - 同心圆环水波 (Ripple)
  - 对角翻滚巨浪 (Diagonal Wave)
  - 声学均衡针雕 (Equalizer Pins)
  - 极速螺旋涡流 (Spiral Vortex)
  - 重低音心跳共振 (Heartbeat Bass)
  - 赛博随机脉冲 (Cyber Glitch)
- **3 挡律动强度增益**：1 挡 (0.5x)、2 挡 (1.0x)、3 挡 (2.0x)。
- **4 挡乐章流变频率**：4 拍 / 8 拍 / 16 拍 / 32 拍。
- **波浪动态幅度调节**与音频矩阵总开关。

### 3. 💎 右侧 Modular Inspector (5 大 Tab 模块化检查器)
- **Tab 1: 材质光学 (Optics & PBR)**：
  - **12 款纯净物理材质**：极光光谱棱镜、高透天然水晶、北极天然冰晶、天鹅绒透光磨砂、黑曜石/琥珀烟晶、重磅真丝、细腻羊绒、蓬松彩云、金耀流沙、珍珠母贝、拉丝合金、冰种翡翠。
  - **8 色经典预设色卡** + 调色盘 + 材质锁定开关。
  - **9 大光学与渲染滑块**：圆角半径、表面粗糙度、折射率 IOR、光学厚度、透射比、彩虹色散 (Dispersion)、呼吸微光晕 (Bloom)、环境反射 (Env Intensity)、影棚主光 (Studio Light)。
- **Tab 2: 矩阵空间 (Matrix & Space)**：
  - 1×1 到 10×10 规格快捷预设与双层立体堆叠。
  - 自定义列数 (Cols)、行数 (Rows)、立体层数 (Layers)。
  - 6 种乐章数目变化序列（标准、膨胀、立体、对冲、聚焦、锁定）。
  - 背景基底调色、预设背景卡与自定义全景背景图像上传。
- **Tab 3: 活体内容 (Avatars & Lyrics)**：
  - **OneWorks 8 款官方活体形象**：云朵精灵、软萌白兔、太阳之子、治愈小熊、忠诚小狗、智能球体、灵动喵喵、闪亮小包。
  - 活体排布（全方阵、中心单体、盲盒群星）+ 交互表情（欢欣雀跃、俏皮眨眼、眼神注视跟随、动态呼吸眨眼）。
  - 歌词与文字排版（5 大对比度/浮雕模式）。
  - 自定义图片/GIF 上传与 1:1 交互裁剪。
  - 内容呈现层级（外表面贴合、内部悬浮内雕、后背衬底透射）。
- **Tab 4: 运镜导演 (Cinematography & Director)**：
  - 基础 FOV 视角与 4 大呼吸变焦模式（重低音冲击、希区柯克滑动、慢速呼吸、抽搐切镜）。
  - 旋转视角模式（自动、常开、锁定）与轨迹（黄金扇形钟摆、360° 全景环绕）。
- **Tab 5: 母带导出 (Master Export)**：
  - MP4 通用格式 (H.264/AAC · 微信/剪映/播放器直出) 与 WebM (VP9 原生) 格式直出。
  - 16Mbps 母带级采样率与 60FPS 实时录制计时器。

## 🌰 『 荔 』(LI) · 暖光藏品伴侣工作室架构

> **“把心事收进兜帽，把好心情留给你。”**
> 
> **具身 3D 萌伴 · 雪沐怪诞手绘透明 UI · 24 款工坊大师 CMF 质感 · Disney 12 弹性动力学 · 音乐共振舞蹈**

### 1. 🧸 双伙伴体系与形态空间
- **荔小卫 (Hoodie)**：
  - **萌颜常态**：温润羊脂玉面容，天然手绘粉嫩腮红，微翘珊瑚粉小舌头。
  - **闭合锁果态**：丝滑无缝形变控制器，蓄力下蹲压缩 -> 缩进果壳闭合 -> 释放回弹，把心事安全收拢。
- **荔小星 (Astro)**：
  - **探索宇航态**：高保真曲面太空头盔、致密宇航服工程构件、背部喷气背包，支持失重漂浮、背包助推与月球大跳。

### 2. 🎨 24 款工坊大师 CMF 材质矩阵
- **01 果壳白玉**：羊脂温白、龙泉粉青、胭脂粉玉、玄青墨玉
- **02 暖绒灯芯**：复古砖红、松针墨绿、芥末姜黄、经典藏蓝
- **03 朱砂凝玉**：故宫剔红（浮雕云纹+24K金箔微粒）、黛赭金漆、霁蓝剔彩、玄黑描金
- **04 全息钛银**：原色钛银（航天缎面拉丝+纳米薄膜干涉）、阳极电光蓝、幻夜曜黑钛、香槟流金钛
- **05 光学水晶**：极地冰蓝、琥珀蜜蜡、祖母绿晶、幻紫水晶
- **06 曜石黑金**：帝王玄黑金（深矿镜面金边）、雪花银曜、青金古矿、赤焰火曜
- **4区语义分区保真算法**：隔离眼眸微表情、白玉肤感保护（防金属刮花与串色）、头顶果蒂叶片谐调色与兜帽躯干大师渐变。

### 3. 🌿 具身动力学与音画共振
- **解析解弹簧阻尼动力学 (`spring.js`)**：质量-弹簧-阻尼二阶微分解算，支持多步时间子步进 (Substepping)。
- **Disney 12 原则弹性伸缩 (Squash & Stretch)**：音乐播放时随 118 BPM 节拍实施体积守恒的自然跳跃与身体律动。
- **次级叶片物理 (`secondary-motion.js`)**：GPU 顶点着色器弹性摆动注入，角色动作触发惯性滞后抖动。
- **视听导播镜头 (`camera-director.js`)**：3 频不可通约正弦漫游，配合低频/中频节拍触发动态 FOV 呼吸与影棚柔光共振。

### 4. ✍️ 雪沐怪诞手绘视觉系统
- **和纸米宣暖色摄影棚**：工坊米宣暖底（`#f5f1ea`）叠加精工微点阵肌理、底座柔和阴影、四角工坊十字靶标（`SPEC 1.0`）。
- **全套手绘透明 UI 资产**：12 款手绘动作卡片（弹跳、挥手、害羞、打瞌睡、律动踩点等）、手绘纸飞机发送按钮、复古涟漪麦克风与鲜荔枝果枝氛围点缀。
- **对话手记**：支持本地互动、智能对话引擎接入与麦克风语音控制微表情。

## 🚀 快速启动

本项目为纯前端轻量单页架构，无任何外部构建依赖，直接启动本地 Web 服务器即可：

```bash
# 使用 Python 启动本地 HTTP 服务器
python3 -m http.server 8089
```

打开浏览器访问：`http://localhost:8089`
