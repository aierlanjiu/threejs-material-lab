## 🌟 品牌命名释义

本项目正式命名为 **『 律 』(LÜ)**（英文副标：`LÜ · 3D Audio-Visual Resonance Lab & Master Player`）：
1. **声律 / 节律 (Acoustic Frequency & Rhythm)**：统摄全功能电台的音频实时 FFT 频谱分析与声波频率律动。
2. **物理之律 (Physical Law & Optics)**：代表 12 款真实 PBR 物理材质（色散、折射率 IOR、体积衰减吸收、各向异性真丝）与数学方阵的自然规律。
3. **编排导演之律 (Director Choreography)**：统摄乐章流变、活体表情凝视、运镜呼吸与 60FPS 母带录制直出的精密秩序。

本项目为纯前端轻量单页架构，无任何外部构建依赖，直接启动本地 Web 服务器即可：

```bash
# 使用 Python 启动本地 HTTP 服务器
python3 -m http.server 8089
```

打开浏览器访问：`http://localhost:8089`
