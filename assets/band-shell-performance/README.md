# 珍珠贝壳 · One day 正式演出声部

本目录将现有九件乐器制作稿接入主站，保留原曲文件用于统一播放时间轴和加载失败时的回退。珍珠贝壳＋海贼王＋One day 时，准备完成后原曲底轨增益为0，实际输出来自九件新编配乐器；新合唱尚未制作，路飞没有伪造歌唱活动。

- `score.json`：原曲摘要、九件乐器事件/能量、分段摘要及休止的主唱；编配版本3。
- `audio/`：完整九轨MP3供分谱独立试听。
- `chunks/`：每轨23段、每段最多12秒，共207段；每段具有独立SHA-256。
- `SOUNDFONT-LICENSE.txt`：保留原采样音源声明。

正常播放只缓存当前与下一组九轨片段。所有片段使用同一AudioContext起播时间；暂停、跳转与切歌取消旧调度，静音/临时独奏仍由原有指挥状态机管理。加载或校验失败时显示准备/错误状态并保留原曲，演员不会以新声部已准备好的状态假演奏。

生成：项目根目录运行 `output/lu-band-runtime/bin/python scripts/package-shell-performance.py`。仅在原音轨和已生成片段不变、需要重新输出索引时使用 `--metadata-only`。原始制作稿位于 `output/lu-band-arrangement/one-day-shell-v1/`。

分段调度和数值检查不替代主观音乐听审、实体手机性能或整首录像验收。
