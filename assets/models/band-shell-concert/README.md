## 视觉与参数

宽扇壳面、深凹曲面、外翻边缘和0.55m母珠金座保留。壳面#cdebe0，透射0.65、原生次表面0.35、半径(1.0,0.8,0.5)、薄膜450nm、清漆0.5；暖色背光与三盏只参与散射照明的内补光增强通透感。母珠沿用上一轮1.2低亮度发光和明暗质感。金边仍为金属度0.95/粗糙度0.12。

台阶完全移除高频凹凸，粗糙度0.06、清漆1.0/清漆粗糙度0.03。八盏吊灯半径0.29/0.32m，移至前缘可见空隙，发光22并使用独立暖色发光颜色；台阶与24颗浮珠发光2.2，中央母珠单独保留原材质。原生增加20处暗槽面光和24处浮珠补光，网页使用面光及六处动态平面反射补足场景内人物/灯光倒影。

八根挂线沿灯球同一X/Y轴垂直垂落，长度至少0.8m；原生辉光从Emission通道提取，Fog Glow阈值0.95、强度2.0、相对尺寸0.12并附暖金色Tint，只将独立灯晕加回原图。脚底软影最大混合0.70、颜色#241e1a；网页在镜面叠加之后绘制脚影。壳面仅对Shadow Ray增加28%透明以缓和交叠暗角，摄像机/反射视线材质保留；远海45–190m渐入最多0.16的晚霞补色，网页Water参与距离雾。

远山高度参数降低约38%，移除高频尖脊，改为灰紫层次与Mist空气透视；140盏港灯在岛湾五组聚落内随机分布，使用三种暖色色调。十名角色按实际透明脚边缘贴合台阶，脚底新增径向软影；原生材质混入6%暖色，网页改为受光材质。原生相机聚焦路飞、f/4；网页以实际颜色通道深度实现最多1.8像素的轻微景深，透明角色轮廓参与深度测试。

原生沿用天空、水面和路飞焦点f/4景深。正面相机Z从7.8降至6.8m，目标高度从3.8升至4.1m，43mm并后退4m保证全舞台；它是较低的取景机位，仍有轻微俯角。网页同步降低主视点，保持自适应完整入镜。Three.js Water、独立DepthTexture双缓冲和固定512天空立方体保持；台阶反射捕获时隐藏自身支撑面及其他镜面/水面，避免遮挡和递归。

原生Cycles中的SSS与网页glTF材质不完全等价。网页使用KHR_materials_transmission与KHR_materials_iridescence（虹彩因子0.45、450nm），不能把一端的效果视为另一端完全相同的光学结果。

## 重建

在可访问Metal的本机执行环境中：

```sh
blender --background --factory-startup --python-exit-code 1 --python scripts/build-shell-concert.py -- --device METAL --samples 96 --width 1920
python3 scripts/export-shell-concert.py
python3 scripts/validate-shell-concert.py
python3 scripts/build-shell-concert-viewer.py
```

代理执行Blender和本地预览服务时按需申请沙箱外权限，不需要改全局权限。仅更新原生文件可使用`--blend-only`；不要把没有运行过的脚本当作验证通过。便携导出器会根据源指纹保留匹配的原生状态，几何或原生构建源有变化时标记stale，重新构建后恢复ready。

交互模式使用`--new-scene`保留用户场景；后台构建在独立进程进行。正式演出页面、角色音频、播放与分轨功能未在本轮改动或发布。动漫角色素材权利归原权利人所有。
