# 珍珠贝壳 · 分层角色制作稿

十位海贼王阵容沿用既有身份与专属乐器，保持2.5D。每位新增原生透明PNG包含身体、头部、左臂、右臂、乐器及表情六个独立绘制分件，共60件。

- `one-piece/manifest.json`：原图尺寸、摘要、分件纹理矩形、连通域遮罩与装配锚点。遮罩防止矩形框带入邻件碎片；图片字节不经脚本重绘或放大。
- 原生实际尺寸均为1374×1145，未达到提示词请求的3072×2560，不称为3K交付。原有素材为每帧256×320的四帧图集；本版是新绘制分层图，不是原图插值放大。
- `shell-performance-review.html`：本地装配与30秒九轨试听。现有主站、舞台检查页、旧角色图集和头像映射保留。
- `scripts/package-shell-cast.py`：复制原生选稿并测量分件。输入索引与全部提示词在`output/shell-performance-20261029/image-jobs.json`；重建需这些原生源文件和现有`output/lu-band-runtime/bin/python`。

身体、头、双臂和乐器可分别变换；当前演奏动作由同一歌曲时间的音符事件驱动，静音或独奏排除的乐器停止动作。表情分件作为后续合唱素材保留，当前不伪造歌词口型或声素同步。路飞在器乐试听中不假唱。

本版用于装配与音乐方向验收；精细指法、逐音乐器接触和最终主站舞台视角仍需后续联调。PNG、遮罩通过不等于最终全曲演奏验收。出处、已知限制和浏览器证据见本轮项目报告。
