# One Piece 2.5D Layered Cast Atlas V2

Native layered sprite atlases and assembly metadata for the 10 One Piece band members in the Pearl Shell Concert.

## Contents

- `manifest.json`: Single source of truth containing bounding rects, connected-component run-length masks, assembly anchor points (`neck`, `bodyNeck`, `leftShoulder`, `rightShoulder`, `instrumentGrip`), and component metadata for all 10 characters across 6 layers (`body`, `head`, `leftArm`, `rightArm`, `instrument`, `mouth`).
- `luffy.png`: Monkey D. Luffy (Lead Vocals / Microphone)
- `zoro.png`: Roronoa Zoro (Bass)
- `nami.png`: Nami (Accordion / Keys)
- `sanji.png`: Sanji (Drums / Percussion)
- `chopper.png`: Tony Tony Chopper (Marimba)
- `robin.png`: Nico Robin (Harp)
- `usopp.png`: Usopp (Acoustic Guitar)
- `ace.png`: Portgas D. Ace (Alto Saxophone)
- `law.png`: Trafalgar Law (Synthesizer / Keytar)
- `shanks.png`: Shanks (Cello)

All atlases are 1374×1145 transparent RGBA PNGs.
