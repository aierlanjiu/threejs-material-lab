# 弈律 · 中国象棋实现任务书

## 边界

- 新增独立入口 `xiangqi.html`，不得修改现有 `index.html`。
- 本地服务优先，不做公网部署与性能压缩。
- 视觉沿用 LÜ 3.0 的矿物白、深钴蓝、朱砂红、半透明 PBR、柔和阴影与精密技术仪器气质。
- Stitch 已定稿：desktop screen `d747f33a0f3949feb539f89a736e1f7c`，mobile screen `8913d44c25374681ae95d35370c3d328`。

## 必做能力

- Three.js 9×10 立体棋盘；圆形倒角棋子，顶部为 14 张原创角色圆形立绘叠加程序化汉字；红黑阵营材质不同。
- 全规则：九宫、象不过河、塞象眼、蹩马腿、炮架、兵过河、飞将、送将过滤、将死/困毙。
- 三模式：玩家对 AI、本地双人、AI 自弈；支持执红/执黑。
- 五档难度：前两档 Wukong，后三档 Pikafish；AI 最短表现延迟 700ms。
- Pikafish 必须是真实 WASM + NNUE 搜索，显示真实 READY / depth / nodes / nps / score / bestmove；加载失败时明确显示并自动降级 Wukong，不得伪造。
- 高档默认 8 线程、512MB Hash（若 WASM 构建上限拒绝则显示实际值）；本地服务提供 COOP/COEP。
- 练习模式显示可走点/提示/悔棋；挑战模式隐藏提示并限制悔棋。分析面板可开关。
- 自动存档、继续对局、FEN 导入导出、JSON/ICCS 棋谱导入导出、逐步复盘。
- 程序化落子/吃子/将军音效；吃子使用材质驱动的粒子/波纹效果，不加音乐播放器。
- 响应式桌面与移动端；键盘可用、按钮与棋格有 aria-label，支持减少动态效果。

## 验收

- Node 规则测试通过；真实 Pikafish 搜索返回合法四位着法。
- Chromium 桌面 1440×1000 和移动 390×844 无横向溢出、无控制台错误。
- 实际完成一次玩家走子、AI 回应、悔棋、FEN 导入、模式切换和自弈启动。
