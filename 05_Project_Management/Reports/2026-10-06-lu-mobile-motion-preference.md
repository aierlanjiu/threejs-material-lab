# 律：手机静止问题的减少动效路径修复

## 复现与处理

- 线上 `index.html` 与提交 `eb1bd7b` 的文件哈希一致，排除了此次核查时远端没有上一版修复的问题。
- 在 390×844 手机视口模拟系统“减少动态效果”后，即使播放状态为真，机械魔方的 FOV、机位 X 和方阵整体高度变化均为 0。关闭系统减少动效后，同一页面的运镜恢复。用户实体手机的系统设置尚未得到确认，因此这是可复现的静止路径，不能单凭模拟断言它就是该设备的唯一原因。
- 在主画面新增明确提示与一键“开启完整音乐演出”入口；默认继续遵循系统设置，用户点击后恢复乐章、FOV、魔方动作、歌词过渡和实时头像动效。选择写入本机浏览器的 `localStorage`，刷新后保持。
- 调整了按钮在桌面与手机上的实际点击位置；自动化真实点击曾发现桌面按钮被播放器遮挡，现已修正。

## 验证

- `node test/lu/music-performance.test.js` 覆盖系统减少动效下的静止状态、点击后的机械魔方和关闭歌词两种模式、FOV、机位、方阵位移与 CSS 过渡；两种模式点击后 FOV 范围分别为 3.44° / 3.26°，机位 X 范围为 1.50 / 1.43，方阵高度范围为 0.138 / 0.103。

- `node test/live_avatar_motion.test.js` 与 `git diff --check` 通过。实体手机、Safari／微信内置浏览器仍需设备侧复核。
