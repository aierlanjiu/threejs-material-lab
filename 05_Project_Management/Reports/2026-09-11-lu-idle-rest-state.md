# 静息待机态：让装置在"没人操作、没有音乐"时也是活的

Agent: 大江南（DSH 会话）· 2026-09-11

## 背景与判断依据

产品定位校对为**个性化音乐氛围装置**（而非素材生产工具）后，重新按"体验价值单位 = 在场分钟数"审查开局路径，发现一处结构性缺口：

默认状态下 `contentMode='material'` / `isPlayingMusic=false`，而波形要求 `live`、相机要求 `shouldMoveCam`、序幕要求 `isPlayingMusic`，三者全部挂在播放态上。**结果是新用户点开后看到的是一块完全静止的 4×4 方阵加一个五 Tab 检查器**——装置必须先被"操作"才会呈现美感，这与氛围装置"不通电也在散发气场"的定义相反。

本轮只做这一件事：**让装置在未演奏时自主呼吸**。不涉及玉牌、分享链路、材质库，是纯加法。

## 关键变更

- `index.html`（与工程副本 `threejs_material_lab/index.html` 哈希一致）
  - 新增静息包络 `state.idleBreath`：上升缓慢（时间常数 ≈1.8s，装置"醒来"需要几秒），下降干脆（≈0.17s，音乐一响立刻交还控制权，不允许两套画面同时驱动）。
  - 新增「13-b 静息待机态」区块，合成一组**纯时间驱动**的呼吸量，只走两条通道：整面等比呼吸缩放（±2.0%、约 12s 一个来回）与深度方向极缓行进波 + 微倾。
  - 相位使用 `cellD / cellDiag / l` 等 **1-Lipschitz 坐标**，刻意不用格坐标：球面与圆环阵型上真正相邻的两块在格坐标里可能相距很远，用格坐标会让它们反向运动、相对位移翻倍顶穿位移预算。
  - 静息只占用一个缩放通道（空间缩放不额外乘 `m.targetScale`）——空间缩放与单块缩放相乘才是真实占位，两个通道一起用会把几何契约的余量吃两遍。
  - 相机：`auto` 档在静息时同样接管镜头；静息构图用 0.09 / 0.021 rad/s 两个不可通约的低频叠加，让机位呈现不出可预期循环。旧的"待机时瞬间吸附机位"分支（`camera.position.x = ...` 直接赋值 + `camMotionMode==='on'` 门控）已删除，改由同一条平滑路径处理，避免两套逻辑同时写相机。
  - 静息态受 `state.waveMotion` 总开关约束：用户关掉律动是明确意图，装置不应继续自己动；`prefersReducedMotion` 下静息完全静止。

## 验证结果

- **新增** `test/lu/idle-rest-state.test.js`（CDP 虚拟时钟驱动，判据按帧数而非墙上时间，避免受渲染速度影响）：
  - 待机 600 帧：`idleBreath` 峰值 0.997；中心块累计位移 0.3593、垂直行程 0.2027 世界单位（旧参数 0.5 倍幅度时仅 0.175/0.102，肉眼不可辨，故上调至满量程 `ampBase`）。
  - **避让求解器推动峰值 = 0 对、最大修正 0.0000、生效帧 0/600** —— 静息呼吸完全没有触碰位移预算，穿模风险为零。
  - 交接：播放前 `idleBreath=0.963` → 播放 300 帧后残留 `0.0000`，音乐起时静息干净退出。
  - 待机全程页面错误 0。
- **既有几何回归未受影响**：`LU_QUICK=1 node test/lu/main-view-geometry.test.js` → 3 档 × 7 阵型 × 2 波形，相交组 0；`samples=4`、`pitch=1.475`；阵型过渡最深瞬时穿透 0.035（与此前记录同量级）。
- **跨端**：390px 手机与 1440px 桌面各 200 帧，`idleBreath≈0.92`、横向溢出 0、推动 0、错误 0。
- **视觉取样**：`output/playwright/idle-rest-visual-qa.js` → `idle-rest-f030/180/360/540/720.png`，第 360 帧与第 720 帧对比可肉眼确认方阵起伏与镜位漂移（此前 0.5 倍参数下几乎不可见）。

## 发现的问题与解决方案

| 问题 | 处理 |
| --- | --- |
| 静息幅度照搬演奏态的 0.5 倍，实测不可感知（几像素） | 位移取满量程 `ampBase`：相邻格相位差 Δφ=0.30 rad，相对位移 ≈0.31A，远低于预算，"看得见"与"不穿模"可同时成立；缩放提高到 ±2% |
| 旧的待机相机分支用直接赋值改机位，与主平滑路径冲突 | 删除该分支，静息走同一条 lerp 路径，仅换用更慢的振幅与频率 |
| 无头浏览器 rAF 被节流到 1–2fps，初版按墙上时间计时导致假失败 | 改用 CDP 虚拟时钟 + 按帧计数判据 |

## 遗留问题与后续建议

- 本轮**未提交、未发布**，等待确认。
- 背景图为静态贴图，而相机在静息时缓慢漂移，远景不产生视差。静息态下"装置感"因此弱于"相框感"，如需强化可考虑背景微视差或改用渐变/纯色基底。
- 静息呼吸目前与音乐完全解耦（不读任何音频量）。若后续希望"音乐停止后装置缓缓退回静息"，当前 `idleBreath` 的上升时间常数（≈1.8s）已是合适的落回速度，无需另建机制。
- 下一步候选（按"减少出戏"排序）：① 把个性化角色从 Inspector 第三层提到第一眼；② 消灭卡顿（P95 26.1ms 已超 60fps 预算）；③ 把沉浸模式从逃生口变成"造境 → 在场"的主路径仪式。
