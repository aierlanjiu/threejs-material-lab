# 『律』机械魔方控件与运镜修复

日期：2026-10-10 · Agent：codex

## 交付范围

本轮按用户确认的「先只修机械魔方模式」完成机械魔方的波形、运动档位、节拍、振幅、头像排布、内容呈现、层级、工艺及相关参数与运镜验证。

此前获准的运镜／FOV 修复，以及反重力主题表情与播放录制时切换卡顿的两项修复，已在范围收窄前完成并验证。本轮保留这些成果，没有继续扩展反重力的波形或内容控件。

当前改动仅在本机工作树，尚未提交、推送或发布。One day 增补及外文歌词中文翻译未纳入这次实施。

## 问题与修复

| 原因 | 修复结果 |
| --- | --- |
| 自动乐章编排覆盖手选波形与头像排布 | 手选后固定所选；增加「跟随编排」按钮，用户可以明确恢复自动接管；按钮状态随实际排布更新 |
| 三档运动隐含改变节拍切换频率 | 4／8／16／32 拍按旋钮标示执行；三档主要控制动作强度，改档后重建格距与尺寸 |
| 振幅没有控制整个方阵，巨像分支忽略波形 | 振幅同时作用于单体与整体动作；巨像按六种不同共振方式运动，保持整张面孔可读 |
| 手选矩阵尺寸被后续乐章覆盖 | 手动改尺寸或尺寸预设后，序列进入锁定模式，播放跨乐章保留尺寸 |
| 没有图片时图片模式退回角色 | 空图片模式显示上传／选择提示，不伪装为角色模式 |
| 表面全息与清漆使用相同效果 | 全息增加随观察角度变化的彩色衍射；浮雕采用纹理边缘法线起伏；内雕与背衬也接入三种不同工艺 |
| 无内容时仍可点击层级／工艺，内雕被不透明材质遮住时无提示 | 纯材质及空图片状态禁用无效控件；内雕／背衬遇不透明材质时提示使用通透晶体 |
| 部分材质写死光学数值，滑块只改变显示 | 手动粗糙度、IOR、厚度、透射与色散直接传入实际材质；未手动设置的参数保留各材质默认特点 |
| 自动材质变化与选中卡片不一致 | 乐章换材质时同步实际材质名称与卡片 |
| 运镜依赖音乐循环，多处代码争抢 FOV，滚轮只改距离 | 运镜独立逐帧更新；基础 FOV 统一为 10°～100°；滚轮与滑块共用基础值，阻尼过渡并保持；动态变焦围绕基础值变化 |
| 检查器标签与输出偏暗 | 沿用当前设计系统，提高检查器文字、滑块标签与输出的对比度 |

## 使用

刷新本机 `http://localhost:8000/index.html`。选波形或头像排布后会固定所选；点击对应「跟随编排」按钮可以重新交给自动演出。基础 FOV 可拖动滑块或在主画面滚动鼠标滚轮，动态镜头会围绕该基础值运行。
