# 律：运镜抖动与角色实时表情修复

Agent: codex · 2026-09-23

## 问题与证据

- 用户观察到锁定视角后晃动消失。`index.html` 的自动运镜直接使用低音峰值调整相机距离，并以较大角度、较快速度绕行；方阵振幅与运动档位不控制这段轨迹，因此调低它们无法抑制视角晃动。播放暂停时，运镜入口会在音频未就绪处返回，不发生待机运镜。
- `state.mouseNormX/Y` 只被读取，没有任何指针事件赋值；眼神跟随开关开启时仍保持正中。
- 选中角色卡片使用 `still.png`，与舞台实时画布无关；原眼神位移和呼吸尺度在 256 像素画布上过小。

## 修改

- 相机低音驱动增加低通平滑，减小运镜速度、角度和距离变化。相机移动后立即对准目标，避免镜头朝向落后一帧。方阵振幅滑块与运动档位现在同时调节自动运镜幅度。
- 舞台指针移动更新归一化注视坐标，离开舞台后回正；提高眼神位移和呼吸可见度。
- 选中卡片共享舞台实时画布，其他角色继续使用静态缩略图以控制开销。

## 验证

- `node test/live_avatar_motion.test.js`：待机镜头不动、播放时运镜、低档低振幅缩小轨迹、指针跟随及离开回正、表情/眨眼/呼吸像素变化、选中预览随表情变化，全部通过。
- `node test/test_kinetic_lyrics_e2e.js`：歌词双引擎、反重力模式及切换通过，浏览器无报错。
- `npm test`：象棋规则与 AI 测试通过；`git diff --check` 和 JavaScript 语法检查通过。
- 移动端 390×844 模拟触控：实时预览存在，注视坐标响应，页面无报错。人工抽看路飞开心和左右注视帧，表情可见。

## 边界

- 本地浏览器回归使用模拟帧与音频就绪状态；真实音频下的主观舒适度仍需在用户的设备上感受。锁定视角仍可作为完全静止的选项。
