## 焰火声音

使用原生 Web Audio 的确定性噪声、滤波、增益包络与左右声像。前排喷射是主要声部，齐射与较轻的空中爆鸣共用现有焰火事件。连续喷射按实际喷射窗口发声，避免每一帧重启音效。

音效开关默认开启，保存到原乐队设置的 `pyroSound` 字段。关闭、暂停、切歌、跳转及退出乐队会清理或重新排程；跳转不补放已经错过的爆鸣。效果关闭与减少动效路径保持声画一致。

音乐 analyser → masterOutput → 扬声器／录制；焰火独立增益／压缩支路 → masterOutput。焰火不会回流到音乐能量分析，录制包含同样的焰火混音。原始音乐分轨和演奏事件保持原状。

## 纯粒子翼

- 使用实例化粒子四边形与自定义 GPU 着色器沿羽束曲线流动；没有使用翅膀 PNG、视频或外部模型。
- 每侧八束，根部接近白色，外侧冰青／淡蓝；爆点前约 0.6 秒凝聚，约 0.4 秒展开，保持至约 2.6 秒后散开，总尾迹约 4.1 秒，曲尾会缩短。
- 最多同时两位角色：主唱和吉他。海贼王为路飞／乌索普，龙珠为悟空／贝吉塔，火影为鸣人／佐助；按 `instrumentKind` 绑定，不把贝斯误当吉他。实际未绑定的声部不冒领效果；独立编排预览明确属于 demo。
- 桌面每位 2000 粒，窄屏每位 800 粒；复用静态缓冲区，按歌曲时间求姿态。手机收敛翼展，镜头计入翼尖边界。
- 角色深度与其他角色投影区域用于遮挡／柔性避让。翅膀挂在独立节点，未加入原 `body` 包围盒，因而角色命中区域与脚下提醒不会随翼展膨胀。
- 粒子线宽按画布／逻辑视口比例补偿，屏幕 Retina 与导出分辨率保持相称。

高潮属于谱面能量估计，未标作人工听辨的权威高潮标注。

## 验证结果

- 通过：新增弹簧帧率无关性、连续打断、微超调、显示门限、柔和封顶、设置迁移、真实焰火峰值关联与跳转确定性测试。
- 通过：既有舞台、焰火 GLSL 物理、连续喷发、改编独立音轨、指挥状态机与 29 人队形回归。
- 通过：1440／390／375／342px 主页面高潮布局、两位粒子翼、角色最小 44px 命中区、开关不压角色与无页面水平溢出。
- 通过：OfflineAudioContext 实际渲染喷射／空中声音，前排能量更强，左右声像有效，零增益完全静音，结束后无残留信号；主页面开关记忆及暂停清理有效。
- 通过：滚动羽化边界、工作台音效选项、4px 进度条微抖、减少动效、可打断胶囊尺寸与弹出面板回稳。
- 通过：真实触屏事件后的 `aria-pressed` 进入／退出状态，采用等待场景更新的断言；上一轮同步立即读取的验证缺口已补验。
- 通过：有头 Chromium 原生 `ANGLE Metal Renderer: Apple M4`，三个主题的编排预览，主唱／吉他身份及纯粒子效果。
- 通过：实际主页面导出 1920×1080 与 1080×1920 H.264＋AAC，解码中间帧确认两种画幅均含翼效与焰火；音频不是空轨，无数值削波。
- 原生 GPU 样片平均编码帧率约 **45.1／49.7 fps**，时长 **9.003／8.577 秒**；平均音量 **-18.3／-18.1 dB**，最大音量均 **-2.5 dB**。编码帧率仅代表本机这两段导出，不等同于实体手机性能保证。
- 通过：1280／390px 最终工作台实景，DPR=2 下 0.5px 内高光、成员暗色表面、中文标签与无页面横向溢出；截图已目视检查。

## 验证过程中修正的问题

1. 零音量的指数包络仍以 0.0001 收尾，产生微小信号；已在零增益分支使用严格零值，并重新离线渲染通过。原证据 `first-zero-gain-failure.*` 保留。
2. UI 运行时截短 dt，软件 GPU 低帧率下弹簧收敛变慢；改用真实经过时间后，独立打断／回稳检查通过。
3. 第一轮软件录制的准备耗时跨过峰值；最终在暂停状态定位、准备录制后再开始音乐，确保完整覆盖翼效。
4. 原组合录制脚本在两个原生导出完成后，因测试浏览器未声明 `hasTouch` 停在额外触屏步骤。导出本身已独立解码确认；触屏用独立 followup 夹具补验通过，组合脚本已补上该选项，未将其原始失败日志说成全绿。
5. 主题切换截图曾早于异步资源准备结束；最终等主题控件重新启用、时钟到 1.5 秒及两翼可见后，用 Metal 重新截图通过。

早期 `climax-*.mp4` 为软件 GPU 功能记录，不作为最终流畅样片；最终交付使用 `native-climax-*.mp4`。
