## 已确认的操作与表现

| 操作 | 实际行为 |
| --- | --- |
| 点按角色 | 下一拍进入／休止，声音与角色演奏动作同时改变 |
| 四小节接管 | 本曲为 78 BPM、3/4 拍，因此是 12 拍、约 9.23 秒；再次点按重新计时 |
| 自动接回 | 四小节后平滑回到按谱演出；由 WebAudio 提前调度，不依赖视觉帧率 |
| 按住 350ms | 临时独奏；松手立即恢复之前的选择。若原四小节选择已到期，则回到自动合奏 |
| 从按住转为拖动 | 先退出临时独奏再开始拖动，释放后不会残留静音或独奏 |
| 拖动 | 调整站位，本首内保留，暂停／拖动进度不会丢失；切换歌曲清除本首站位 |
| 暂停 | 冻结音乐时钟与接管余时；继续后接着计算 |
| 拖动进度 | 取消临时声音干预，按新时间位置回到自动演出；保留本首站位 |
| 键盘 | Enter／空格支持点按与按住；Escape、取消触摸或失去焦点安全结束临时手势 |

播放时，真实休止成员使用原休止帧，配合轻微身体摇摆；不会因为补足舞台人数而假唱或假演奏。已配器的音符、力度和实测能量驱动演奏。主奏按原配器接力，合奏段十名角色都实际参与，短暂音符休止仍然存在。

角色旁只显示必要状态：下一拍、休止／剩余小节、独奏、自动接回。透明原生按钮提供键盘焦点和触屏命中，最小 44px；并非另一套可见成员控件。首次手势提示会退隐，保留原播放器和折叠乐谱。
