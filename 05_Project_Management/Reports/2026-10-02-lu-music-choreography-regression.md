# 律：音乐编排、镜头与表情回归修复

## 根因与修复

- 旧的 `isLyricMode = mode !== 'off'` 守卫把机械魔方模式的自动运镜和动态 FOV 一起禁用了。现在只对物理反重力模式锁定正面 30° 机位；机械魔方和关闭模式均执行原有乐章编排。
- 乐章配置中的 `fov` 形态没有再写回运行状态，导致圆环段落的抽搐切镜等镜头谱失效。现在每次乐章切换同步阵型、波形和 FOV 形态，并更新控制按钮状态。
- 关闭模式原镜头幅度过小，待机摆动也没有节拍落点。提高轨道镜头与变焦的可见度，增加随节拍交替的整体偏航、轻微翻滚和升降；用户关闭声波运动或系统启用减少动态效果时仍遵循对应开关。
- 新的实时头像模块保留了自主眨眼和情绪循环，但音乐表情触发已断开。现在按小节首拍、第三拍和中频能量触发开心、眨眼、唱歌；用户手动选择的表情优先。
- 运动镜头与窄 FOV 容易把圆环裁出画面；演出机位按阵型外接半径和即将到来的最窄 FOV 预留画幅。

## 验证

- 新增 `test/lu/music-performance.test.js`。原版本在机械魔方模式下 FOV 与镜头 X 位移均为 0，测试先失败；修复后覆盖机械魔方、关闭模式、表情、乐章切换、抽搐切镜和圆环四角不出画。
- 回归测试通过：机械魔方 FOV 范围 5.48°、镜头 X 范围 6.37、整体升降范围 0.210；关闭模式分别为 5.50°、4.58、0.226；抽搐切镜 FOV 范围 16.0°，圆环投影最大纵向坐标 0.872（小于画框边界 1）。
- 390×844 浏览器视口播放实际《游京》：机械魔方第 19–26 拍切到螺旋阵型，关闭模式第 32–40 拍切到圆环；两段的 FOV、镜头 X 和整体高度均有变化，表情出现唱歌、开心与自主循环。两种模式均无页面脚本错误，画面见本地 `output/playwright/lu-music-slot-final.png` 与 `output/playwright/lu-music-off-final.png`。
- `node test/live_avatar_motion.test.js`、`npm test`、几何快速回归与 `git diff --check` 通过。手机实景为浏览器模拟视口，实体手机性能尚未验收。
