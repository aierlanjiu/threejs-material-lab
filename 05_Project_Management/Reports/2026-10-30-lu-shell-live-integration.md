# 珍珠贝壳正式演出：模型、分层角色与九轨接入

Agent: codex。任务开始于2026-10-29，跨日继续。

## 范围与实际实现

用户在审阅AGY实现后确认继续，修复定稿模型、新角色、新九轨没有进入正式演出的缺口，以及验收脚本缺少失败断言的问题。

- 主站使用`band-shell-stage.js`读取并校验定稿舞台、环境GLB及天空，保留其曲面、材质、吊灯和真实台阶；临时圆柱舞台不再用于shell演出。交付GLB和原生场景未重建。
- 海贼王十位使用`band-cast-v2`原生PNG与60分件，复用制作间的遮罩、身体/头部和双臂装配。动态纹理桌面512×640、手机256×320；原始PNG未改写。
- 自动编队采用真实台面上的错位弧排，通过向下射线得到支撑高度，减少低机位下的遮挡；保留手动编队、角色设置及台面拖放。拖放保留手指与角色的相对位置，离开台面时不接受悬空位置。
- 艾斯的中央站位向前调整至母珠完整半径之外，浏览器截图已确认身体和萨克斯不再被母珠遮挡；顶栏补齐珍珠贝壳名称。
- shell＋海贼王＋One day读取独立编配版本3，输出九件新编配乐器。原曲保留播放时间轴与错误回退功能；新轨就绪时原曲底轨增益为0。新合唱仍未制作，路飞休止，界面明确提示。
- 九轨每轨23个片段、每段最多12秒，共207段MP3，逐段校验SHA-256。正常仅缓存当前/下一组，避免同时解码九首完整立体声音轨。完整九轨MP3供分谱试听，总资产及索引约116.7MB。
- 原有奶油/海岛、其他歌曲和阵容保留原路径。改过的入口与依赖统一版本标记，并另开52612本机预览，以便和既有运行实例区分。
- 制作间验收将角色裁切、九轨播放、静音/独奏、播放互斥、手机溢出、脚本错误改成失败即退出的断言。琴弓边缘像素检查只证明未裁切，不冒充逐音弓弦接触验收。

## 已执行的验证

- `npm run check`：16/16通过，包含新增的2项：207片段/九轨摘要与所有权、缺失合唱休止；共用时钟、独立静音、跳转与两组缓存上限。
- 新编配通过`validateBandScore`、`validateArrangement`及实际`loadBandAnalysis(preferShell=true)`路径检查。
- 新增/修改JS语法、打包脚本执行和`git diff --check`通过。
- 制作间严格浏览器验收通过：10人60分件、9轨解码、静音冻结/恢复、独奏/恢复、全曲互斥、390/320px无横向溢出，香克斯0/5/15/25秒边缘像素计数均为0。证据`browser/strict/final-browser-state.json`；已人工查看香克斯琴弓截图。边缘计数不替代全部接触姿态验收。
- 主站完整有界验收退出码0，`browser/final/validation.json`为`passed=true`：版本3、`rendered-stems/playing=true`、9轨、原曲底轨增益0；11.7秒跨至12.94秒，缓存[1,2]；跳至65.72秒，缓存[5,6]；390/320px无横向溢出。奶油→贝壳返回样本86.77秒，仍在播放且原曲底轨增益0。没有pageerror；软件GPU有ReadPixels停顿及并行编译扩展不支持警告，不作为性能通过证据。
- 最终桌面、390/320和减少动态截图已人工查看：六片主壳完整，十人入镜且桌面可辨，艾斯无母珠遮挡。部分脚部接触点很小，未做逐点精确测量；单张减少动态截图也不证明所有运动都已降低。
- 主站验收区分三个状态：模型就绪、本地曲库绑定原曲、AudioContext真正播放。冷启动模型先于曲库就绪时，现有播放器会拒绝空源播放；验收须等待媒体绑定后再点播放。九轨缓存`ready`只证明可启动，新增`playing/contextState/contextTime`诊断后，实际播放断言还要求时钟前进。
- 播放器会正常自动隐藏。风格切换验收先通过真实指针移动唤醒，再验证按钮中心命中并点击，不通过强制点击或修改隐藏状态绕过交互。

## 保留的验收缺口

- 新歌词合唱没有制作；原唱导唱不作为新合唱交付。
- 和声、音色与混音的主观听审待确认。
- 实体手机触控、帧率、温升与Safari未验；手机模拟无横向溢出不代表这些项目通过。
- 整首有声录像导出与线上发布尚未在本轮完成。
- 手机全景受横向舞台比例限制，演员比桌面小；全景适配和单人辨识度须分别验收。
