# 演奏 pet 素材

29 位成员沿用 `js/avatar/instrument-manifest.js` 的身份和专属乐器。
形象及演奏关键帧由内置 GPT 图像生成工具制作，参考现有透明头像和
用户于 2026-10-13 确认的完整 pet／真实舞台视觉稿。

每个 `.webp` 是透明的 1024 × 320 图集，横向四格，每格 256 × 320：

1. 休止／准备姿态。
2. 演奏起势。
3. 演奏重拍。
4. 演奏回收。

运行映射见 `js/avatar/band-pets.js`。演奏循环取 1、2、3、2；休止、
减少动态效果或动作速度为零时取第 0 格。选择帧使用歌曲时间轴。
角色和乐器作为一个整体绘制，不是头像贴在几何体上。

`scripts/prepare-band-pets.py` 只对生成像素进行透明区域分离、统一
注册、缩放和图集编码。每个角色的四帧共用尺度和裁切范围，脚底基线
为单帧高度的 94%。原始生成稿、提示词和验证数据保留在本机
`output/lu-band/pet-generation/`；素材准备脚本需要 Pillow。
