# 律 · 局部动态视窗 ASCII / Dither

- Agent: Codex（实现、Node 测试、替代运行方式下的浏览器回归与提交）；browser_verify（浏览器工具诊断）；架构与四个对抗角度只读审阅。
- Scope: 入场背景图槽位及其三主题、横／竖画幅。前景魔方、标题、主题图按钮与现有开幕动作不参与滤镜。

## 反馈修订：局部视窗与适度动态

用户反馈整幅过滤观感一般，本次将默认效果改为左右两块柔边视窗，一主一次，中央和大部分原图直接保留。只让视窗缓慢漂移与轻微呼吸，图像及字符网格固定，避免整幅闪烁或字符抖动。

- 新设置 `region: 'window' | 'full'` 与 `motion: boolean`，两种滤镜独立保存。面板可切换局部／全幅、缓动／静止；减少动态偏好始终使用静止呈现。
- 新默认值：ASCII 遮罩 52、强度 78、尺寸 28、间距 10；Dither 遮罩 24、强度 72、尺寸 12、间距 0。两者默认局部视窗与缓动，色板仍为 Original。
- 存储版本升到 v2，避免旧版全幅重遮罩参数覆盖新的轻量默认；旧版存储不删除。
- 完整滤镜帧与未遮罩混合帧缓存，只在设置／素材变化时重新采样；动态最多 24fps，仅更新小遮罩并合成。隐藏、停用、静止、全幅与销毁均停止持续调度。
- 淡入终帧强制达到 100%；快速切换从当前混合帧继续，避免残影和跳变。

## 实现

- 新增 `js/effects/effect-settings.js`、`effect-layer.js`、`effect-panel.js`，以及入场接线 `js/ui/lu-intro-effect.js`。
- 设置对象为 `{filter, mask, palette, inkTone, strength, size, spacing, region, motion}`。两种滤镜各自记忆参数，恢复推荐值只影响当前滤镜；本地保存并同步已打开的入场标签页。
- ASCII 使用真实素材亮度采样、8/92 分位归一化、指定字符集、字体／网格和 HSV 提亮；Dither 使用 4×4 Bayer 与逐通道量化。五套色板和 Original 可切换。
- 滤镜帧按需重画，设置变更 72ms 合并，滤镜／色板切换 150ms 淡入；减少动态时直接切换。采样长边约 480px，显示像素比不超过 1.6，任一画布边不超过 2048px。
- 单次采样结果镜像到左右帷幕内的 2D canvas，保留现有开幕变换，未增加 WebGL renderer。图片失败回退原图，同一 URL 下次可重试。
- `intro-effects.html` 是入场背景的独立预览区。桌面图片与 420px 面板并列，窄屏上下排列，面板从不覆盖图片；由入场左下角入口打开。主入场尺寸和前景布局不变。

## 适配取舍

参考提示词的 cover-fit 会改变现有入场的构图，因原背景一直使用 `100% 100%` 拉伸。为优先满足“原位且保持构图”，本槽位与预览显式使用 `fit: 'fill'`，可复用 Layer 默认仍为 cover。原有标题与主题按钮的局部 radial scrim 保留在效果上方。

当前素材是静态图片，所以只实现图像采样路径，不加入无用途的视频逐帧调度。局部 ASCII 与轻缓视窗动态为默认；可取消启用回到原图。预览实景已审阅；主入场加载、实体手机温升／GPU 与其他浏览器仍在验证边界之外。

## 审查与修复

- 保留原背景构图，防止原图对比时裁切跳变。
- 原有前景可读性遮罩保留在 Canvas 上方。

- 临时图片请求失败不缓存失败状态，下次显式换图／重播可重试。
